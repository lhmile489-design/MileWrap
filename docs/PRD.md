## 1. 产品概述

Mile Warp 是一款运行在 Windows 本机的桌面应用，用来集中管理和运行终端类 AI agent（Claude Code、Codex CLI、Kimi Code 等）。

用户把每个「项目目录 + agent」的组合保存为一个**工作区**，按自己的方式分组归类。点开工作区，应用在内嵌终端里启动对应 agent。同一个工作区可以开多个会话，控制台支持 1 格 / 左右 2 格 / 四宫格三种布局，用户可以自由把会话摆到任意格，让多个 agent 并行跑不同的任务；左侧除会话树外还有当前目录的文件树，随时看清 agent 改动了什么。

### 1.1 要解决的问题

| 现状 | 痛点 | Mile Warp 的做法 |
| --- | --- | --- |
| 每次开 agent 都要手动开终端、`cd` 到项目、再敲命令 | 重复操作多，项目一多就记不住路径 | 工作区保存目录、agent、启动参数，一键启动 |
| 多个 agent 开在多个终端窗口里 | 窗口来回切换，分不清哪个窗口在跑哪个项目 | 左侧按分组列出工作区与会话，带运行状态 |
| 想让两个 agent 对比或分工执行任务 | 需要手动排两个窗口 | 控制台区内置 1 / 2 / 4 宫格，会话可拖拽换格 |

### 1.2 目标用户

单人开发者（本机用户本人），日常同时使用多个终端 agent，项目数量在 5 到 50 个之间。

### 1.3 本机环境基线（2026-10-31 实测）

| 项 | 结果 |
| --- | --- |
| 系统 | Windows 11 Pro for Workstations |
| Node / npm | v20.19.0 / 10.8.2 |
| Claude Code | `claude` 2.1.312，位于 `C:\Users\LHmile\.local\bin\claude.exe`（另有 npm 版 `claude.cmd`） |
| Codex CLI | `codex` 0.161.0，位于 `C:\nvm4w\nodejs\codex.cmd` |
| Kimi Code | `kimi` 0.29.1，位于 `C:\Users\LHmile\.kimi-code\bin\kimi.exe` |
| Shell | Windows PowerShell 5.1；**未安装 PowerShell 7（pwsh）** |
| Windows Terminal | 已安装（`wt.exe`） |

实测发现两处会影响实现的细节：

- `claude` 有两份安装。PATH 中 `C:\nvm4w\nodejs`（第 32 项，npm 版 `claude.cmd`）排在 `C:\Users\LHmile\.local\bin`（第 48 项，独立安装版 `claude.exe`）之前，在 PowerShell 里敲 `claude` 实际走的是 npm 版。
- `codex` 只有 npm 生成的 `codex.cmd` 批处理壳，内容是用 `node.exe` 运行 `node_modules\@openai\codex\bin\codex.js`。批处理壳不能被 `CreateProcess` 直接执行，处理方式见技术设计 §5.2。

### 1.4 技术栈

与 `E:\WebApp\Mile-Terminal-Management\mile-terminal-management`（Mile Terminal 2.3.0）保持同一套技术栈和视觉语言，版本号逐项对齐，详见技术设计 §2。

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Electron 43 + electron-vite 5 + electron-builder 26（NSIS） |
| 界面 | React 19 + TypeScript 5.9 + Tailwind CSS 4 + zustand 5 |
| 终端 | node-pty 1.1（ConPTY）+ xterm.js 6（fit / webgl / search / web-links 插件） |
| 图标与字体 | Phosphor Icons；Manrope（标题与数字）+ Segoe UI Variable（正文）+ Cascadia Mono / Consolas（终端） |

## 2. 角色与权限

只有一个角色：本机用户。应用不做登录、不联网同步。agent 自身的登录与鉴权由各 CLI 自己处理，Mile Warp 不读取、不保存任何 agent 的密钥。

## 4. 核心用户流程

### 4.1 首次使用

1. 打开应用，左侧显示一个空的「未分组」和引导卡片「新建第一个工作区」。
2. 应用后台检测 `claude` / `codex` / `kimi` 是否可用，结果显示在 agent 下拉中。
3. 用户点「新建工作区」，填写名称、选择 agent、选择目录（系统文件夹选择框），保存。
4. 工作区出现在列表中，状态为「未启动」。

### 4.2 启动一个 agent

1. 单击左侧工作区。
2. 当前聚焦格如果为空，直接在该格启动；如果已经显示着别的会话，则把原会话转入后台，在该格启动新会话。
3. 终端里出现 agent 的界面，左侧该工作区状态变为「运行中」，展开可见该会话条目；目录栏切到该工作区目录。
4. 再次单击同一工作区（或右键「新建会话」）可在该工作区下再开一个会话，会话栏展开显示两个会话子行。

### 4.3 宫格并行

1. 点击标题栏布局按钮，在 1 格 / 左右 2 格 / 四宫格之间切换；切到 2 格或 4 格时，新增的格为空状态。
2. 在左侧会话或工作区上右键选「在第 N 格打开」，或直接拖到目标格。
3. 多个 agent 同时运行；点击哪一格，键盘输入就进哪一格。
4. 把一格里的会话拖到另一格，两格内容交换；布局与每格对应关系持久化。

### 4.4 整理工作区

1. 新建分组「客户项目」。
2. 把相关工作区拖进该分组，或在编辑弹窗里修改「所属分组」。
3. 双击工作区名称或在编辑弹窗中修改显示名称和备注。

### 4.5 关闭应用与恢复

1. 有运行中会话时点关闭，弹窗列出运行中的会话，给出两个选项：
   - 「最小化到托盘」：窗口隐藏，会话继续运行；托盘图标显示会话数，点击恢复窗口。
   - 「全部结束并退出」：结束所有进程后退出。
2. 两种方式都会把当前会话快照写入本地记录（工作区、agent、目录、参数、会话标题、所在格）。
3. 下次打开应用，控制台显示「恢复上次的 3 个会话」卡片，点击后按原样重新拉起并**续接上次的对话**（Claude `--resume <id>`、Codex `resume <id>`、Kimi `--session <id>`），同时恢复到上次的宫格布局与对应格；每行标注「续接」或「新开」，可逐条改成新开。
4. 进程本身不能跨重启存活，恢复的含义是「重新启动 agent 并续接上次的对话」，不是「接上原来的进程」。续接靠各 agent 自己的会话 ID，应用不重放历史输出，终端画面由 agent 续接后重绘；某条拿不到 ID 时在恢复卡片上标为「新开」。

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动到可操作 < 2 秒；单个终端持续输出时界面不卡顿（可见的格用 WebGL 渲染，最多 4 个上下文）；后台会话照常解析输出但不上屏；四宫格同时运行时内存增量 ≤ 600MB |
| 稳定性 | 单个 agent 崩溃不影响其他会话和主界面；PTY 进程随应用退出全部清理，不留僵尸进程；托盘模式下关窗口不结束会话，只有显式「全部结束」或系统关机才终止 |
| 安全 | 渲染进程关闭 Node 集成、开启上下文隔离与沙箱；渲染进程只能通过白名单 IPC 调用主进程，不能指定可执行文件；工作区环境变量的值用 Windows DPAPI（Electron `safeStorage`）加密落盘，且不下发渲染进程 |
| 数据 | 配置存本机用户目录 JSON 文件，写入采用「先写临时文件再替换」，防止断电损坏 |
| 编码 | 配置文件 UTF-8 无 BOM；终端输出按 UTF-8 解码，中文路径与中文输出不乱码 |
| 可访问性 | 正文对比度 ≥ 4.5:1；所有操作可键盘完成，focus 可见；尊重 `prefers-reduced-motion` |
| 平台 | 首版只支持 Windows 10 1809+ / Windows 11 x64（ConPTY 要求） |

## 7. 边界与限制（本期不做）

- 不做 macOS / Linux 版本。
- 不做 3 格、5 格以上、自由拖拽缩放的任意宫格；只提供 1 / 2 / 4 三种固定布局。
- 不做标签页式多终端（会话通过会话栏与宫格承载）。
- 不做真正的进程恢复：应用重启后只能按快照重新启动 agent 并续接对话，应用自己不保存、不重放终端输出。
- 不解析 agent 的输出内容（不做对话记录、token 统计、成本统计）。
- 不做云同步、账号体系、多设备。
- 不做 agent 的安装与升级，只检测是否已安装。
- 不做代码编辑器；目录栏只读，不支持新建、改名、删除文件。

## 8. 成功标准

1. 从打开应用到某个项目的 Claude Code 跑起来，只需一次点击。
2. 四宫格里同时运行 Claude Code、Codex、Kimi 与 Shell，交互、颜色、全屏界面与在 Windows Terminal 中一致。
3. 关窗口选「最小化到托盘」后 agent 继续跑；彻底退出再打开，一键恢复上次的会话。
4. 30 个工作区分在 5 个分组里，能在 3 秒内通过搜索或分组定位到目标。
