# 发版冒烟清单

> harness 用的是假 agent 和 Shell，下面这些只能在真机上人工过。每次发版前逐项勾选，结果记在发版说明里。
> 来源：《升级建议》5.5，2026-11-01。

## 续接对话

- [ ] Claude Code：开一个会话说一句话，「全部结束并退出」，重启应用一键恢复，确认接上同一段对话（`--resume <uuid>`）。
- [ ] Codex CLI：同上，确认 `resume <id>` 接上；工作区带了自己的参数时，参数跟在 `resume <id>` 之后也能正常启动。
- [ ] Kimi Code：同上，确认 `--session <id>` 接上；同一目录开两个 Kimi，各自续接到自己的对话。
- [ ] 自定义 agent 填了续接模板时，恢复卡片显示可续接，实际启动参数符合模板。

## 进程与退出

- [ ] 4 个会话运行中「全部结束并退出」，任务管理器里没有残留的 agent / node / conhost 进程。
- [ ] 强行结束应用进程后重启，弹出「上次有 N 个 agent 进程没结束」，确认后进程被结束。
- [ ] `%APPDATA%\mile-warp\logs\` 下有当天日志，里面没有环境变量值和终端输出内容。

## 通知与角标

- [ ] 窗口最小化到托盘时，后台 agent 跑完一轮弹出系统通知，点通知回到那个会话。
- [ ] 任务栏图标右下角显示「等你处理」的数字，看过之后数字减少。
- [ ] 免打扰时段内不弹通知。

## 安装包

- [ ] 干净机器（没装 Node）上安装、启动、卸载，卸载后开始菜单与桌面快捷方式消失。
- [ ] 高 DPI（150% / 200%）下托盘图标、任务栏角标清晰，不糊。
- [ ] 终端里点 `src/foo.ts:42` 能用 VS Code 打开到第 42 行；没装 VS Code 时在资源管理器中定位。
