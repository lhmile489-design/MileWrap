# Mile Warp UI 设计约束

> 版本：v0.2（依据用户参考图重写布局与组件：会话栏 + 目录栏 + 宫格，无底部状态栏）
> 日期：2026-10-31
> 定位：设计令牌与布局的权威说明。代码落地后以 `src/renderer/src/styles/tokens.css` 为准，两者冲突时以 tokens.css 为准并回改本文。
> 风格来源：`E:\WebApp\Mile-Terminal-Management\mile-terminal-management`（Mile Terminal 2.3.0 的令牌体系）+ `E:\WebApp\Claude Fable 5 Max\style-templates\pages\46-dimensional-layering.html`（四级海拔、层级表达）。

---

## 1. 设计方向

一句话：**把「维度分层」搬进工作台**——浅灰画布上一层层浮起的表面，终端是最高一层。

- 视觉语言沿用 Mile Terminal：冷调中性、品牌蓝 `#2563eb` 主按钮、Manrope 标题、无渐变底色、状态色只染描边与胶囊。
- 层级语言借用 46 号模板：四级海拔阴影、顶层毛玻璃、点阵底纹（仅用于画布空白处，不铺在终端上）。
- 和模板的偏离：模板用 Space Grotesk + Inter 并从 Google Fonts 加载；桌面应用离线运行且要中文，改用 Manrope + Segoe UI Variable + 雅黑，字体本地打包。

## 2. 设计令牌

语义令牌名与 Mile Terminal 完全一致，便于直接把 `components/ui/` 移植过来。

### 2.1 表面与描边

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--canvas` | `#f6f7fb` | `#0f1219` | 应用底、画布 |
| `--surface-panel` | `#ffffff` | `#151a23` | 会话栏、目录栏、标题栏 |
| `--surface-card` | `#ffffff` | `#1b212c` | 终端格卡片、对话框 |
| `--surface-raised` | `#eef1f6` | `#232a37` | 悬停底、分段控件底、输入框内凹 |
| `--surface-sunken` | `#f1f3f8` | `#171c26` | 卡片内的凹陷块 |
| `--stroke-base` | `#e3e7ee` | `#2a3240` | 常规描边 |
| `--stroke-strong` | `#cbd2dd` | `#3a4556` | 悬停 / 聚焦描边 |

### 2.2 文字（对比度实测值，白底 / 深色卡底）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--text-strong` | `#1b1f2e`（16:1） | `#f1f4f9` | 标题、当前选中项 |
| `--text-primary` | `#2b3142`（12.7:1） | `#e4e8f0` | 正文 |
| `--text-muted` | `#4c5265`（7.8:1） | `#a3acbc` | 次级说明 |
| `--text-faint` | `#5f6678`（5.7:1） | `#9aa4b5` | 最弱一档，仍 ≥ 4.5:1 |
| `--text-inverse` | `#ffffff` | `#0f1219` | 反色场景 |

**规则：文字色禁止再加透明度**（不写 `text-ink-faint/50`），弱化用更浅的令牌。

### 2.3 信号色与强调色

| 令牌 | 浅色 | 深色 | 语义 |
| --- | --- | --- | --- |
| `--signal-live` | `#15803d` | `#4ade80` | 运行中 |
| `--signal-warn` | `#92400e` | `#fbbf24` | 启动中、需要关注 |
| `--signal-fault` | `#b91c1c` | `#f87171` | 异常退出 |
| `--signal-info` | `#1d4ed8` | `#7aa7ff` | 提示 |
| `--signal-idle` | `#6b7280` | `#8a94a6` | 未启动 / 已正常退出 |
| `--signal-accent` | `#2563eb` | `#7aa7ff` | 品牌蓝、选中态、聚焦环 |
| `--signal-accent-soft` | `#e3ecff` | `color-mix(#2563eb 20%, #1b212c)` | 选中底 |

**状态色只染描边、图标块与胶囊，不染整块卡片底。** 状态永远「颜色 + 图标 + 文字」三重表达，不单靠颜色。

### 2.4 海拔（四级 + 浮层）

| 层级 | 浅色 | 深色 | 对应元素 |
| --- | --- | --- | --- |
| E1 贴地 | `0 4px 14px rgb(20 28 48 / .07)` | 无（表面变亮 + 描边） | 会话卡片、胶囊、输入框 |
| E2 卡片 | `0 8px 22px rgb(20 28 48 / .12)` | 无 | 终端格（非聚焦）、卡片 |
| E3 浮起 | `0 12px 28px rgb(20 28 48 / .14)` | 无 | 终端格（聚焦）、悬停态 |
| E4 浮层 | `0 16px 40px rgb(20 28 48 / .16)` | `0 16px 40px rgb(0 0 0 / .45)` | 对话框、菜单、命令面板 |

深色主题不用阴影表达层级：`canvas → panel → card → raised` 逐级变亮，每级加 1px 描边。**深色只保留 E4 一档阴影。**

### 2.5 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-card` | 16px | 终端格卡片、对话框、大磁贴 |
| `--radius-control` | 10px | 按钮、输入框、菜单项、小面板 |
| `--radius-pill` | 999px | 状态胶囊、标签、分段控件 |

禁止任意值圆角（不写 `rounded-[13px]`）。

### 2.6 字体

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-display` | `'Manrope', 'Segoe UI Variable Display', 'Segoe UI', 'Microsoft YaHei UI', sans-serif` | 标题、数字、品牌 |
| `--font-sans` | `'Segoe UI Variable Text', 'Segoe UI', 'Microsoft YaHei UI', sans-serif` | 正文、控件 |
| `--font-mono` | `'Cascadia Mono', 'Cascadia Code', Consolas, 'Microsoft YaHei UI', monospace` | 终端、路径、端口、快捷键提示 |

- Manrope 经 `@fontsource/manrope` 本地打包，不依赖 CDN。
- 本机未安装 Cascadia Mono，实际回落 Consolas；两者 x 高度接近，切换时只需复核一次终端行高。
- 终端字号 13px、行高 1.5（与 Mile Terminal 一致）；UI 基准字号 14px，**最小 12px**。

### 2.7 间距与动效

- 间距基数 4px，允许值：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。
- 曲线：`--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)`；`--ease-out: cubic-bezier(0.32, 0.72, 0.32, 1)`。
- 时长：按下 60–70ms；颜色与描边 150–200ms；弹起与 hover 抬升 200–400ms。动效只用 `transform` / `opacity`。
- `prefers-reduced-motion` 下移除位移与缩放，只保留颜色变化。

没有底部状态栏。参考图里没有，四宫格又吃纵向空间；会话数、agent 版本这类信息分别放到托盘图标提示和设置页「Agent」里。

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| 标题栏 | 高 40px | `titleBarStyle: 'hidden'`，渲染层自绘；空白处 `-webkit-app-region: drag`，控件区 `no-drag`。左：会话栏显隐、目录栏显隐、宫格切换 `Segmented`（1 / 2 / 4）；中：全局搜索触发框；右：主题、设置、窗口控件 |
| 会话栏 | 默认 200px，可拖 160–320px，折叠为 56px 图标栏 | 参考图最左列：顶部筛选框 + 新建按钮，下面是「分组标签 + 工作区卡片」竖向列表 |
| 目录栏 | 默认 240px，可拖 180–400px，可整体隐藏 | 参考图第二列：当前选中会话所在目录的只读文件树，顶部是页签区与操作按钮 |
| 控制台 | 剩余全部 | 内边距 8px；格间距 8px；1 / 2 / 4 三种布局；底纹为点阵 |
| 格 | 圆角 16px | 格头 40px + 终端区；聚焦格 `2px` accent 描边 + E3 |
| 分隔条 | 视觉 2px，命中区 6px | 悬停变 accent，水平 `col-resize`、垂直 `row-resize`；会话栏、目录栏与控制台之间的边也是分隔条 |

**窗口与最小格**：窗口最小 1024 × 640，每格最小 360 × 240（PRD T-02）。两栏都展开时 1024 宽窗口的控制台只有 1024 − 200 − 240 = 584px，四宫格每格 (584 − 16 − 8) / 2 = 280px，不够。所以控制台可用宽度 < 744px（= 2 × 360 + 8 + 16）时按顺序自动处理：

1. 先临时收起目录栏。1024 宽下控制台 = 824px，四宫格每格 (824 − 24) / 2 = 400px，满足。
2. 仍不够（窗口缩得更窄，实际被最小宽度挡住，理论兜底）再把会话栏收成 56px 图标栏。

自动收起是临时的：窗口变宽后自动弹回；用户手动收起 / 展开的选择优先，不被自动逻辑覆盖。高度方向：1024 × 640 下控制台高 = 640 − 40 − 16 = 584px，四宫格每格 (584 − 8) / 2 = 288px，满足 240 的下限。

**宫格切换**：标题栏的 `Segmented` 在 1 / 2 / 4 间切换。`2 → 1` 时第 2 格会话转入后台（会话栏仍可见、仍在运行），`1 → 2` 自动接回；`2 → 4` 时新增两格为空态；`4 → 2` 时下排两个会话转入后台。

## 4. 组件规范

### 4.1 会话栏

对应参考图最左列。三层数据（分组 > 工作区 > 会话）在视觉上压平：**分组 = 一行标签，工作区 = 一张卡片，会话只在多开时才展开成子行**。

- **头部**：高 36px。左：筛选输入框（占位「筛选会话…」，13px，按名称 / 备注 / 目录 / agent 过滤）；右：24px「+」按钮，点开菜单「新建工作区 / 新建分组」。
- **分组标签行**：高 28px，名称 12px/600 `--text-muted`，前面可选 8px 色点（W-13）。点击折叠 / 展开该分组下的卡片（箭头 12px，悬停才显示，旋转 200ms spring）；悬停右端浮出「新建工作区」「⋯」。标签行不是卡片，没有底色。「未分组」固定在最后。
- **工作区卡片**：高 48px，圆角 `--radius-control`，水平内边距 10px，卡片间距 4px。
  - 左：agent 徽章 24px。
  - 右上行：状态图标（见下）+ 名称 13px/600，超长省略号。
  - 右下行：分支图标 12px + 分支名 12px `--text-faint`；目录不是 git 仓库时改显示备注，备注也没有则显示目录末段。
  - 最右：被显示在某一格里时，显示格号小标（1–4，12px，圆角 6px，`--surface-raised` 底）；该工作区下有 2 个及以上会话时再加会话数胶囊。
- **多会话展开**：会话数胶囊点击展开，卡片下方缩进 32px 出现会话子行，高 32px：状态点、`#2` 序号 `--text-faint`、会话标题 13px（双击改名）、运行时长 `tabular-nums` 12px。只有 1 个会话时不出现子行，点击卡片直接定位到该会话。
- **状态图标**（参考图用绿色实心方块表示运行中；形状加文字提示，不单靠颜色）：

| 状态 | 图标 | 颜色 | 悬停提示 |
| --- | --- | --- | --- |
| 未启动 | 空心方块 10px | `--signal-idle` | 未启动 |
| 启动中 | 虚线描边方块 | `--signal-warn` | 启动中 |
| 运行中 · 对话中（3 秒内有输出） | 实心方块 10px，呼吸 + 外扩光晕 | `--signal-live` | 对话中 |
| 运行中 · 等待输入（安静了） | 描边方块内一个小实心块，静止 | `--signal-accent` | 等待输入 |
| 正常退出 | 方块内对勾 | `--signal-idle` | 已退出（0） |
| 异常退出（无法对话） | 实心方块 + 反色感叹号 | `--signal-fault` | 异常退出（N） |

只有「对话中」有动画；动画只用 `opacity` 与 `transform`，`prefers-reduced-motion` 下全部去掉（形状与文字仍能区分）。活动状态由主进程按输出时间判断（`session:activity`），渲染层不看输出内容。

- **选中卡片**：`--surface-raised` 底 + 左侧 2px accent 竖条，文字用 `--text-strong`；不做整卡描边，也不用 accent 色写文字（浅色下 accent 在 accent-soft 上只有 4.36:1，不达标）。
- **悬停**：浅一级底色，不抬升（卡片列表很密，抬升会抖）。
- **拖拽**：拖动中卡片 `opacity: .6`，落点位置显示 2px accent 插入线；拖到格上时该格出现 `2px` 虚线 accent 边框 + 顶部提示「放到此格」。
- **折叠态（56px）**：只显示 agent 徽章 + 状态图标，名称放 tooltip；分组标签变成一条 1px 分隔线。

### 4.1.1 目录栏

对应参考图第二列。

- **头部**：高 36px。左：页签区，首版只有「文件」一个页签（参考图这里有多个页签，其余留给 P2，不画禁用占位）；右：「刷新」「在资源管理器打开」「收起」三个 24px 图标按钮。
- **上下文行**：头部下方一行 28px，显示「工作区名 · #会话序号」12px `--text-muted`，说明这棵树属于谁；悬停显示完整路径（`--font-mono`）。
- **树节点**：高 28px，缩进按层级 14px；根目录行默认展开并有 `--surface-raised` 底；文件夹 `▸` 16px（展开旋转 200ms），文件用类型图标 16px；名称 13px，长名省略；`.git`、`node_modules` 之类默认显示但灰化（`--text-faint`），不隐藏。
- **选中与悬停**：悬停 `--surface-raised`；选中 `--signal-accent-soft` 底 + `--text-strong` 文字。
- **状态**：加载中显示 12px 骨架条；空目录显示「空目录」`--text-faint`；越界或不可读显示错误文案 + 「重试」。
- **只读**：没有新建 / 重命名 / 删除入口；右键菜单只有「在资源管理器中显示」。
- **联动**：点击会话栏的卡片或子行、或点击某一格，目录栏切到对应工作区目录；树的展开状态按工作区各记一份，切回来保持。

### 4.2 终端格

- **格头**（高 40px）：左起 agent 徽章 24px、工作区名 13px/600、分支 chip（分支图标 12px + 分支名 12px，`--surface-raised` 底，圆角 `--radius-pill`）、目录 12px `--text-faint`（中间省略，悬停显示全路径）；运行时长 `tabular-nums`；右端状态胶囊 + 图标按钮组（重启、结束、清屏、最大化、关闭），图标 16px。格宽 < 480px 时目录收起，只留名称、分支、时长和状态。
- **聚焦**：`box-shadow: 0 0 0 2px var(--signal-accent), var(--shadow-float)`；非聚焦 `1px` `--stroke-base`。**不降低非聚焦格的内容透明度**（终端内容不能变淡）。
- **空格**：画布点阵底纹上放一张居中卡片：标题「把工作区拖到这里，或从左侧选择」+ 最近 3 个工作区的快捷按钮。有可恢复的会话时，卡片上方多一块「恢复上次的 N 个会话」，列出会话（工作区名 + agent + 目录 + 「续接」或「新开」标记，可逐个取消勾选，也可把某条改成新开），底部「全部恢复」主按钮与「忽略」幽灵按钮。
- **退出条**：终端底部 36px 条，左侧「进程已退出，代码 N」，右侧「重新启动」「打开 Shell」两个次级按钮。
- **不做格底快捷条**：参考图终端底部有一排快捷入口（远程控制、文件浏览、富文本输入等），这是 Warp 自己的功能，首版不仿，避免和 agent 自己的输入框抢焦点。

### 4.3 Agent 徽章

不用品牌 logo（拿不到官方矢量、也避免商标问题），统一用**字母缩写 + 分类色**：

| Agent | 缩写 | 底色 | 前景 | 说明 |
| --- | --- | --- | --- | --- |
| Claude Code | `C` | `#b8461f` | `#ffffff` | 暖橙偏深，对比度 5.34:1。（初稿的 `#d97757` 配白字只有 3.12:1，不达标） |
| Codex CLI | `X` | `#1f2328` | `#ffffff` | 深墨，深色主题改用 `#e6edf3` 底 + `#1f2328` 字 |
| Kimi Code | `K` | `#1a4fd6` | `#ffffff` | 蓝，与 accent 同族但更深，6.70:1 |
| Shell | `>_` | `--surface-raised` | `--text-primary` | 中性 |
| 自定义 | 首字母 | 用户选色 | 自动取黑或白 | 从预设 8 色板中选，保存时校验前景对比度 ≥ 4.5:1 |

徽章圆角 6px，尺寸 20 / 24 两档，字号 12px / 700，居中。

### 4.4 标题栏

左：logo 22px + 品牌名 13px/800，之后依次是会话栏显隐、目录栏显隐两个 28px 图标按钮和宫格切换 `Segmented`。中：全局搜索触发框（宽 360px、上限 40vw、高 30px，占位「搜索会话、Agent…」，右侧 `Ctrl+Shift+K` 键帽），点开是命令面板，首版搜索工作区、会话和可执行动作，文件搜索留 P2。右：主题切换、设置、三个窗口控件（46×40 命中区，贴边只换底色不下沉）。

### 4.5 浮层

- 对话框：E4 阴影 + `--surface-card` + 圆角 16px；遮罩 `rgb(15 18 25 / .28)` + `backdrop-filter: blur(8px) saturate(160%)`（**只用于固定遮罩，不用于滚动容器**）。
- 菜单：`--surface-card` + 圆角 10px + E4，项高 32px，图标 16px，危险项用 `--signal-fault` 文字。
- 所有浮层走统一的 `useOverlay`：Esc 只关最上层、焦点陷阱、关闭后还焦点。

## 5. 键盘

| 组合 | 行为 |
| --- | --- |
| `Ctrl+Shift+K` | 打开全局搜索（命令面板） |
| `Ctrl+Shift+B` / `Ctrl+Shift+E` | 显隐会话栏 / 目录栏 |
| `Ctrl+Shift+F` | 终端内搜索 |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | 复制 / 粘贴 |
| `Ctrl+Tab` | 在可见格之间循环切换焦点 |
| `Ctrl+Shift+1`–`Ctrl+Shift+4` | 焦点切到第 N 格 |
| `Ctrl+Shift+D` | 宫格模式循环：1 → 2 → 4 → 1 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 终端字号 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 关最上层浮层；焦点在终端时交给 agent |

**原则**：焦点在终端里时，应用只拦截 `Ctrl+Shift+` 组合与字号快捷键，其余全部交给 agent（PRD T-18）。例外是 `Ctrl+C`：有选区时先复制并清选区、不发中断；无选区时照常发给 agent（PRD T-07）。单键快捷键在输入框与终端内不生效。

## 6. 可访问性与底线

- 正文对比度 ≥ 4.5:1（令牌表已标注实测值）；禁用态不压整块 `opacity`，用弱化底色 + 可见描边。
- 所有可操作元素有 `:focus-visible` 3px accent 环，偏移 2px。
- 主操作「图标 + 文字」；纯图标按钮必须有 `aria-label`。
- 状态不只靠颜色：颜色 + 图标 + 文字。
- 窗口 1024 / 1280 / 1920 宽度下无横向滚动；最小窗口 1024 × 640 下，两栏展开的四宫格会自动收起目录栏（见 §3），需验证不溢出、格宽 ≥ 360。
- `prefers-reduced-motion` 下去掉位移、缩放、呼吸动画。
