## 1. 现在已做（地基，不再重复提议）

- **并行**：1/2/4 宫格、拖拽换格、后台保活回放、布局预设、分组全部启动/结束、广播输入（默认关、开启需确认）、路径插入终端。
- **可见性**：主进程活动状态（active/quiet/idle）、会话/格头状态区分、Windows 通知 + 任务栏闪烁 + 角标、免打扰时段。
- **恢复**：快照即时写盘、一键恢复续接（Claude/Codex/Kimi/Pi）、孤儿进程检测（pid+exe+确认）、退出归档旧批次。
- **Git**：G0–G3 + 风险确认面板（内容指纹信任）；改动/暂存/丢弃（一次性 token）/diff/提交（跑 hooks）/分支/远端（进度、取消、互斥、协议白名单）/工作台/历史/目录栏改动标记。
- **历史**：四 agent 只读适配器（列表/搜索/预览/导出/续接）。
- **Skills**：M0–M4（扫描/详情/卸载/跨 agent 安装/GitHub/zip，解压加固）。
- **外围**：文件预览栏（Markdown/图片，含 sanitizer）、目录栏只读树、命令面板、快捷键体系、托盘、设置。
- **工程**：IPC 安全模型（`isTrustedSender` + `sanitize*` + 渲染层只传 id/token）、一次性 token 模式、atomicWrite + `.bak` + `.corrupt`、显式版本迁移、`verify-*.cjs` 约 700+ 断言（`verify:all` 17/18）。

剩余缺口三类：**恢复与崩溃的救生索**（续接失败兜底、主进程异常兜底、日志可查）、**真实性边界**（真实 agent/远端/升级路径从未自动验证过）、**注意力管理**（十几个会话里「先看哪个」仍靠逐格扫）。

## 4. 中长期 · P2（按需挑，不设里程碑）

- **会话**：预设带每格 initialCommand（依赖 P1-2）；会话子行「最后输出时间」相对时间；格头「等你」文字徽标；续接 `resumeId` 在会话属性中可见可复制；`Ctrl+Shift+J` 跳下一个等你的会话。
- **Git**：历史搜索 / 按文件看历史（`--grep` / `git log -- <path>`，G-33）；远端链接（解析 `remote.origin.url` → GitHub 仓库页/新建 PR 页，只构造 URL）；worktree 标注与 `git worktree list` 入口；工作台历史页分支纵向连线（按 parent 关系排，不解析内容）；栏头「N 改 · M 暂存 · 领先/落后 · 冲突」一句话摘要。
- **命令面板**：`>` 前缀文件搜索（主进程受限 DFS，上限 50 条、3 秒超时）与 `#` 前缀历史搜索（面板文件搜索是 PRD 原留 P2，历史功能已落地可顺手接入）。
- **历史写操作（§9 拍板后）**：Claude/Kimi/Pi 改名与删除（回收站、运行中拒绝、`sessionRecords` 联动）；Codex sqlite 写库放最后且单独授权。
- **Skills 二期**：同名对照批量安装（SK-09）；skill 详情图片（受限读图频道，越界判定复用 `fs:readImage`）；GitHub 来源更新检查（SK-10，收益低）。
- **界面**：UI 缩放 100%/125%/150%（只调 CSS 变量基准，不用 `setZoomFactor`——与终端字号打架；格最小尺寸与窗口最小尺寸按比例放大；先做探针）；标题栏标记「目录栏被自动收起」。
- **结构卫生**：`main/index.ts`（795 行、8 个域）拆 `main/ipc/*` 注册表；`sanitize*` 集中成 `lib/validate.ts`；`__warpDebug` 面文档化（`docs/DEBUG-SURFACE.md`）；速查浮层加筛选框。
- **其他**：新建弹窗「最近用过的目录」下拉；演示工作区（Shell + 临时目录）入口；自定义快捷键（升级建议 3.6）。

## 5. 暂不建议做（三份报告共识 + 既有决策）

1. **解析终端输出做任何推断**（等待确认的问题识别、token 统计、AI 总结对话/diff）：PRD §7 边界，输出格式私有且漂移；Git 摘要只做统计与导航。
2. **标签页 / 自由宫格 / 3 格以上布局**：PRD §7 已定。
3. **代装/代升级 agent**：提示安装命令到此为止。
4. **云同步 / 账号 / 多设备**：`MILE_WARP_DATA_DIR` 指向同步盘即可由用户自解。
5. **凭据管理界面**：Git 凭据交给系统 helper/SSH agent，不存凭据是安全卖点。
6. **skills.sh 市场（SK-11）**：依赖第三方站点 + 不可信内容分发，与受控安装定位矛盾。
7. **目录栏写操作**：「只读目录树」决策仍有效；复制/插入路径已覆盖真实需求。
8. **Codex sqlite 写库**：即使 §9 放行也排最后；别名层已覆盖改名主要价值。
9. **命令面板全文搜索文件内容**：要建索引成本高，只做文件名。
10. **`Ctrl+W`/`Ctrl+R` 单 Ctrl 快捷键收归应用**：M5 决策放给 agent，不变。

### 阻塞项（条件到了再动）

- **检查新版本**：无发布地址；有了只做「提示 + 链接」，不自动下载。
- **代码签名**：需购证书；有证书后 electron-builder 配签名即可消除 SmartScreen。

## 6. 需要用户拍板的问题

1. **会话历史写操作范围**（《会话管理升级计划》§9 六问）：删除/改名的回收站语义、运行中会话策略、Codex 写库授权。别名层（P0-5）不依赖此拍板。
2. **待处理队列数据源**：「异常退出」是否计入待处理数？建议计入——退出本身就是需要人看的信号。
3. **风险面板钩子内容预览**：展示钩子文件前 3 行是否可接受（可能含敏感路径）？建议接受——用户要看的就是「它要跑什么」。
4. **后台会话 IPC 推送策略**：`session:data` 后台是否仍推 chunk（取决于 slot 衔接兼容性实测，先在 `verify-m3` 回放用例里验证再定方案）。
5. **UI 缩放实现路线**：CSS 变量基准（保守，不含终端）vs `setZoomFactor`（整体放大但与终端字号冲突）？建议前者并先探针。
6. **命令面板文件搜索范围**：已加载树（轻）vs 主进程受限遍历（全但需超时/上限）？建议受限遍历，目录栏内过滤覆盖已加载部分。
7. **主进程崩溃后策略**：是否引入 supervisor 自动重启，还是仅保快照+提示？建议后者（Node uncaught 后状态不可信）。
8. **`MILE_WARP_LIVE_*` 环境变量**打包后是否禁用（与 `MILE_WARP_TEST_*` 策略对齐）。
